# android_packages_apps_SamsungServiceMode

Port do aplicativo ServiceMode (*#0011# / *#06#) da Samsung para permitir diagnósticos de rede e rádio celular em ROMs puras AOSP.

## 🛠️ Tecnologias

- **Java**
- **Android SDK**
- **Telephony / RIL**

## 📂 Estrutura do Projeto

- `src/`: Lógica do discador e comandos AT de rádio.
- `res/`: Layouts e menus de diagnóstico.
